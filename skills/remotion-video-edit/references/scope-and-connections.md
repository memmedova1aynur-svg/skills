# Əhatə və əlaqələr

## Bu skill nə edir

- Remotion ilə 1080×1920, 30 fps şaquli tanıtım videosu (Reels / TikTok / Shorts) qurur: storyboard → layihə → Studio önizləməsi → təsdiqdən sonra render.
- Danışıq yazılarında boşluqları və təkrar / səhv cümlələri yerli faster-whisper transkripti ilə kəsir; kəsim siyahısını Remotion-da `Series` ilə tətbiq edir.
- Kinetik tipoqrafiya, spring animasiyalar, təbəqəli keçidlər və vurğu anına sinxron səs effektləri üçün hazır şablonlar verir.

## Nə etmir

- Paylaşım etmir və planlaşdırmır. Render faylını istifadəçiyə təhvil verir; paylaşım həmişə istifadəçinin təsdiqi ilə ayrıca addımdır.
- Ssenarini və ya hook-u sıfırdan yazmır; mətn hazır deyilsə, əvvəlcə uyğun yazı skill-inə yönləndirir.
- İstifadəçinin öz səsinə kəsimdən başqa emal (səviyyə, EQ, səs-küy azaltma) tətbiq etmir.
- Səsləri qulaqla dinləyə bilmir; bunu istifadəçiyə açıq deyir.
