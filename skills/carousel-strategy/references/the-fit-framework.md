# The FIT framework

**F**ix one goal → **I**dentify the content type (+ an optional helper) → **T**reat it
visually. Writing starts only after all three are decided.

## F — Goals (one per carousel)

| goal | what counts as success | typical ending |
|---|---|---|
| views and reach | non-followers see it | none needed, or a follow |
| saves | readers keep it to use later | "save for when you…" |
| shares | readers send it to someone | "send to a colleague who…" |
| comments and discussion | readers answer, argue, add | a real question tied to the topic |
| expertise and trust | readers see how the expert thinks | none, or a pointer to related work |
| profile visits | readers want more from the author | a pointer to the series or highlights |
| applications | readers ask about the service or programme | one concrete next step |

## I — The 21 content types

| # | type | what it does | flow (flexible) | builder slide types |
|---|---|---|---|---|
| 1 | Explainer | splits one concept into simple parts | cover → what it is → parts → example → recap | cover, text, list, recap |
| 2 | Step-by-step | shows how to do one concrete task | cover → result → steps (one per slide) → common slip → recap | cover, text (steps theme), recap |
| 3 | List | collects methods, ideas, tools, examples | cover → one item per slide or a list slide → recap | cover, list, text |
| 4 | Checklist | lets readers check their own work | cover → why check → checklist slides → what to do if "no" | cover, recap, list |
| 5 | Problem–solution | names a concrete difficulty, gives workable ways out | cover (the situation) → why it happens → 2-4 solutions → first step | cover, text, list |
| 6 | Mistakes and fixes | the approach that causes the problem, and its alternative | cover → mistake/fix pairs → rule of thumb | cover, compare |
| 7 | Myth–reality | tests a common belief with an argued explanation | cover → myth/fact pairs with sources → what to do instead | cover, compare, recap |
| 8 | Comparison | shows the difference between two methods or choices | cover → criteria → side by side → when to choose which | cover, compare, table |
| 9 | Before–after | shows a change and explains why it changed | cover (after) → before → what changed and why → after | cover, image, annotated, compare |
| 10 | Case study | situation → action → observed result → lesson | cover → situation → what we did → what we observed → lesson | cover, text, stat, annotated, recap |
| 11 | Storytelling | an event told in scenes the reader wants to follow | see `storytelling-rules.md` | cover, text, image, quote |
| 12 | Expert position | argues a view with reasons, observations, examples | cover (the claim) → reasons → counter-view → where it holds | cover, text, quote |
| 13 | Ready tool / template | material ready to use | cover → what it's for → the template → how to fill it | cover, table, annotated, image |
| 14 | Resource collection | books, apps, materials, each with why | cover → one resource per slide with its use → recap | cover, list, image |
| 15 | Q&A | answers the main questions on a topic or service | cover → one question per slide → where to ask more | cover, text |
| 16 | Test / choice / scenario | a situation, a choice, then the reasoning | cover → scenario → options → answer and why | cover, quiz, answer |
| 17 | Behind the scenes / process | how the work was prepared and decided | cover → stages with real photos → decision points → result | cover, image, text |
| 18 | Reviews and participant experience | real feedback with context and application | cover → context → real quotes (with permission) → what changed | cover, quote, image |
| 19 | Service / programme presentation | who it's for, what happens, what you get, how it runs | cover → for whom → what we do → outcome → process → how to apply | cover, list, table, poster, cta |
| 20 | Photo story / event diary | photos in a meaningful sequence; each frame adds information | cover photo → frames with one line each → takeaway | cover (image), image |
| 21 | Humour / familiar situations | everyday situations of the audience, within professional limits | cover → situations → a light useful turn | cover, meme, comic |

**Useful combinations:** storytelling + practical takeaway · case study + checklist ·
comparison + template · problem–solution + step-by-step · myth–reality + resource collection ·
scenario test + expert position.

## T — Visual formats

Choose the format for comprehension, then keep the client's palette, fonts and rules.

| format | use it when | carousel-builder |
|---|---|---|
| Typographic | the idea is in the words; strong headlines | `minimal`, `bold`; text, list |
| Editorial / magazine | opinion, essays, stories with a photo | `editorial`; cover with `image` |
| Infographic | relations, numbers, timelines, tables | `data`; stat, table, compare |
| Photo + explanation | real images carry the proof | image slides, cover `image` |
| Card system | one method, role, question or tool per slide | `steps` or `minimal`; text with `autoNumber` |
| Annotated example | a worksheet, screenshot or material explained in place | `annotated` |
| Continuous panorama | the carousel should read as one object | built into `minimal`, `bold`, `data` |
| Collage / scrapbook | notes, photo fragments, documents | not built in: compose the collage as one image, use image slides |
| Dialogue / comic | a situation told through conversation | `comic`, `tweet` |
| Mixed media | image, text card and short video together | stills here; the video slide comes from a video tool |
| Photo story | real frames tell the event | image slides in sequence |

Don't apply the same design to every topic. Vary the format across a page's month while the
brand system (colours, type, badge) stays constant.

## Varying across clients and weeks

Keep a simple log per page: date, type, format, goal. Before planning, look at the last 8-10:
avoid a third consecutive carousel of the same type or format, and avoid the same ending twice
in a row.
