# Remake Recipes: templates and a worked example

Copy these shapes. Every deliverable fits on one screen so the user can film from a phone.

## 1. Source card (after Retrieve)

```
SOURCE   @creator, Instagram Reel, posted 2026-10-02, 0:24, 9:16
STATS    410k views | creator has 18k followers | their usual: ~6k views   -> ~68x outlier
LEVEL    3 (video-eyes: 9 shots, 3.4 cuts/10s, speech from 0.2s, transcript: faster-whisper)
COMMENTS "sending this to my sister", "why does no one teach this", "part 2??"
GAPS     can't identify the background song (no label visible)
```

## 2. Beat sheet (after Examine)

```
| # | Time      | We see                          | Said                              | On-screen text        | Job     |
|---|-----------|---------------------------------|-----------------------------------|-----------------------|---------|
| 1 | 0.0-1.8   | Face close-up, holding a letter | "My landlord tried this on me."   | "he didn't expect #3" | Hook    |
| 2 | 1.8-4.1   | Letter close-up                 | "Rent up 18%, two weeks' notice." |                       | Tension |
| 3 | 4.1-8.0   | Laptop screen, scrolling law    | "One: check the cap..."           | "1. the cap"          | Payoff  |
| … |           |                                 |                                   |                       |         |
| 9 | 21.5-24.0 | Face, smiling                   | "He took it back."                | "save this"           | Turn+CTA|
```

Driver line under the table:

```
DRIVER   hook = a conflict with a common enemy + a promise ("#3") that forces a watch-through
LEVER    practical value with identity ("this is so us") -> saves + shares to family
NOT IT   the song, the kitchen background, her outfit (counterfactual: still works without)
VERDICT  go: small account, ~68x outlier, mechanism transfers to any "you're being overcharged" niche
```

## 3. Remake script (after Adapt)

Same beat timings, user's substance.

```
MODE     A (same format, new topic) | for: freelance designer account
HOOK     0.0-1.8  Face close-up holding a phone with an email open.
                  SAY: "A client tried this on me last week."
                  TEXT: "he didn't expect #3"
BEAT 2   1.8-4.1  Phone close-up: the email.  SAY: "Unlimited revisions, same price."
BEAT 3   4.1-8.0  Screen: your contract template.  SAY: "One: the revision clause..."  TEXT: "1. the clause"
...
BEAT 9   21.5-24.0 Face. SAY: "He signed the new scope."  TEXT: "save this"
LOOP     Last line sets up the first ("...and that's why I always check what clients try first")
CAPTION  keyword first line + one question that invites stories
COVER    Frame 1 with the hook text, readable in the profile grid crop
AUDIO    Add a trending sound from the in-app library at low volume under the voice
```

## 4. Shot list (film it in 20 minutes)

```
[ ] 1  Face close-up, phone in hand, natural light from a window    (2 takes of the hook line)
[ ] 2  Phone screen close-up with the email (blur the client's name)
[ ] 3  Screen recording: scroll the contract to the revision clause
[ ] 4  Screen recording: the scope document
[ ] 5  Face, reaction to the client's reply
[ ] 6  Face, final line + "save this" gesture
Settings: 9:16, 1080x1920, keep text inside the center safe zone (away from the caption and buttons)
```

## 5. Edit plan (CapCut or any editor)

```
- Cut on every beat timestamp above; total 24s
- Captions: auto-captions on, 2 to 4 words per line, center-low but above the caption area
- On-screen text on beats 1, 3, 5, 7, 9, appears 0.2s after the cut
- No gap longer than 0.4s of silence (trim breaths)
- Export 1080x1920, 30fps
```

## 6. Publish block (WoopSocial)

```
PLATFORM  Instagram  | postType REEL | file: remake-final.mp4 | cover: cover.jpg
CAPTION   <final caption>
WHEN      Thu 2026-10-22 18:30 (user's audience time zone)

PLATFORM  TikTok     | MEDIA_UPLOAD (lands in drafts; add a trending sound in-app, then post)
CAPTION   <TikTok caption with 1 to 2 keywords>

-> Show both to the user. Publish only after an explicit yes.
```

## 7. Read-back (48 to 72 hours later)

```
REMAKE    3,140 views, 212 saves, 41 shares (collectedAt 2026-10-24 09:00 UTC)
USUAL     ~900 views per reel (last 10 reels, same source)
SOURCE    68x outlier for its creator; ours: ~3.5x our usual
LESSON    the conflict hook transfers; saves were high, so the practical payoff landed
NEXT      remake the next outlier from the same list in mode A; test face vs text-only frame 1
```

Numbers in these templates are illustrative placeholders for the shape only. Real runs use
the visible counts and metrics with their dates, never estimates.

## Worked example: when to say no

Source: a 9-second reel from an account with 3.2M followers, 900k views (their usual ~1.1M).
Outlier score: below their normal. The views came from the audience, not the content.

The right output is short: "This isn't an outlier for that creator, so it doesn't prove the
format works. Want me to look at their reels that did 3x their usual, or find a smaller account
in your niche with a real hit?" No beat sheet, no remake.
